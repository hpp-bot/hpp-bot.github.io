快速开始 ​

bash
# 克隆公开仓库
git clone https://github.com/hpp-bot/vitedocs-content.git
cd vitedocs-content

项目架构 ​

仓库类型内容访问方式
vitedocs-contentPublic文档内容 (Markdown)公开克隆
vitedocs-themePrivate主题样式 (CSS/组件)仅通过 CI/CD 拉取
hpp-bot.github.ioPublicGitHub Pages 部署用户访问

两者的联动方式：

  1. 修改私有仓库的 .vitepress/theme/ 文件
  2. 推送 commit，触发 GitHub Actions workflow
  3. Workflow 自动克隆公开仓库的文档内容并构建
  4. 自动部署到 GitHub Pages

详细文档请查看 双仓架构指南。
